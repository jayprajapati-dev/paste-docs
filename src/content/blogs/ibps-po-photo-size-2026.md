The Institute of Banking Personnel Selection (IBPS) Probationary Officer exam requires a photo and signature upload. The specifications are shared across IBPS PO, Clerk, and RRB exams.

## IBPS PO Photo Specifications

| Parameter | Specification |
|-----------|--------------|
| Dimensions | 200 × 230 pixels |
| File size | 20 KB to 50 KB |
| Format | JPG / JPEG |
| Background | Plain white |

## IBPS PO Signature Specifications

| Parameter | Specification |
|-----------|--------------|
| Dimensions | 140 × 60 pixels |
| File size | 10 KB to 20 KB |
| Format | JPG / JPEG |
