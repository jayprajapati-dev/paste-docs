The UIDAI (Unique Identification Authority of India) Aadhaar portal requires document uploads for address updates, name corrections, mobile number linking, and biometric updates. Each document has specific file size and format requirements.

## Aadhaar Document Upload Specifications

| Document Type | File Size | Format | Notes |
|---------------|-----------|--------|-------|
| Identity proof (PAN, voter ID) | Max 100 KB | PDF/JPG | Scan or photograph |
| Address proof (bank statement, utility bill) | Max 100 KB | PDF/JPG | Recent (within 3 months) |
| Photo for update | Max 1 MB | JPG | If updating photo |
| Signature scan | Max 100 KB | JPG | For signature update |
| Biometric exception photo | Max 1 MB | JPG | If biometric exception |

## How to Compress Aadhaar Documents

### For 100KB cap documents (ID proof, address proof)
Use the [Compress to 100KB tool](/tool/compress-100kb) for images, or the [Compress PDF tool](/tool/pdf-compress) for PDFs.

### For 1MB cap uploads (photo update)
Use the [Compress to 1MB tool](/tool/compress-1mb).

### If your document is a photo that needs to be PDF
Use the [Image to PDF tool](/tool/image-to-pdf) to convert, then compress with the Compress PDF tool.

## Aadhaar Update Process

1. Visit the UIDAI Self-Service Update Portal
2. Enter your Aadhaar number and OTP
3. Select the field to update (name, address, photo, etc.)
4. Upload the supporting document (compressed to under 100KB)
5. Submit and note the Update Request Number (URN)

## Why Aadhaar Documents Should Never Be Uploaded to Random Servers

Your Aadhaar contains your 12-digit unique identity number, biometric data, and personal information. Uploading Aadhaar documents to untrusted online compressors risks:
- Identity theft
- Aadhaar number exposure in database breaches
- Unauthorised linking to bank accounts / SIM cards

Browser-based tools like PasteDocs process Aadhaar documents entirely in your device's RAM. No part of the document is transmitted to any server.
