The State Bank of India Probationary Officer (SBI PO) online application requires you to upload a photograph and a scanned signature in specific formats. If either upload does not meet the spec, the application form will not let you proceed to the fee payment step.

This guide covers the exact SBI PO 2026 photo and signature specifications, how to prepare both in under 5 minutes, and how to avoid the most common rejection reasons.

## SBI PO 2026 Photo Specifications

| Parameter | Specification |
|-----------|--------------|
| Dimensions | 200 × 230 pixels (passport size) |
| File size | 20 KB to 50 KB |
| Format | JPG / JPEG |
| Background | Plain white |
| Photo date | Recent (within last 6 months) |

The SBI PO photo cap is 50KB — the same as most Indian banking exams (IBPS, RBI). Note that the **minimum is 20KB** — if your photo is under 20KB, the portal considers it too low quality and rejects it.

## SBI PO 2026 Signature Specifications

| Parameter | Specification |
|-----------|--------------|
| Dimensions | 140 × 60 pixels |
| File size | 10 KB to 20 KB |
| Format | JPG / JPEG |
| Background | Plain white (sign on white paper) |

The SBI PO signature cap is 20KB — stricter than NEET (30KB) but the same as SSC and IBPS.

## How to Prepare Your SBI PO Photo and Signature

### Photo preparation

1. Stand against a plain white wall in daylight. Face the camera directly with both ears visible. Use your phone's rear camera.
2. Use the [Passport Size Photo tool](/tool/passport-size) to crop to 413×531 px (which scales to the SBI requirement). Or use the [Custom Size tool](/tool/custom-resize) and enter "200x230 px".
3. Use the [Compress to 50KB tool](/tool/compress-50kb) to bring the file under 50KB. If the result is under 20KB, use a larger source image.
4. Verify the file size is between 20KB and 50KB.

### Signature preparation

1. Sign on a plain white unruled sheet with a black or dark blue pen.
2. Photograph the signature in daylight using your phone's rear camera.
3. Use the [Signature Resize tool](/tool/signature-resize) to crop to exactly 140×60 pixels.
4. Use the [Compress to 20KB tool](/tool/compress-20kb) to bring the file under 20KB.
5. Verify the file size is between 10KB and 20KB.

Both the photo and signature processing run entirely in your browser — no upload to any server.

## Common SBI PO Application Rejection Reasons

1. **Photo file size outside 20-50KB** — the most common rejection. Use the iterative compress tools to land within the range.
2. **Signature file size outside 10-20KB** — use the Compress to 20KB tool.
3. **Wrong dimensions** — photo must be 200×230 px, signature must be 140×60 px. Use the dedicated tools to apply the exact dimensions.
4. **Background not white** — use the [Add White Background tool](/tool/white-background) for photos with shadows or off-white backgrounds.
5. **File format is PNG instead of JPG** — SBI requires JPG. Use the [PNG to JPG converter](/tool/png-to-jpg) if needed.

## Frequently Asked Questions

**What is the SBI PO photo size?**
The SBI PO photo must be 200×230 pixels in JPG format with a file size between 20KB and 50KB.

**What is the SBI PO signature size?**
The SBI PO signature must be 140×60 pixels in JPG format with a file size between 10KB and 20KB.

**Can I use the same photo for SBI PO and IBPS PO?**
Yes. Both exams have the same photo specification (200×230 px, 20-50KB) and signature specification (140×60 px, 10-20KB).

**Is my photo uploaded to a server when I use PasteDocs?**
No. PasteDocs processes everything in your browser using the Canvas API. Your photo and signature are processed in your device's local memory and never transmitted to any server.
